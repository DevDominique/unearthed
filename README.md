# 🌿 Unearthed

A full‑stack Node + Express gift‑finding app with full CRUD functionality, dynamic routing, and database‑backed persistence. Built to showcase backend engineering fundamentals, RESTful API design, and clean server organization while providing a simple interface for browsing and managing curated gift ideas.

---

## ✨ Features

- Browse a curated list of gift ideas  
- View individual gift details  
- Create new gift entries  
- Edit existing gifts  
- Delete gifts  
- Dynamic routing for all gift pages  
- Custom 404 page  
- Organized server architecture (routes, controllers, database layer)  
- Persistent storage via relational database

## 📦 Dependencies

> This project requires a local or hosted database.  
> Developers should create their own database and `.env` file before running the server.

To run this project locally, you will need:

- Node.js (v18+ recommended)
- npm or yarn
- Express.js
- PostgreSQL (or any relational database)
- A `gifts` table matching the project schema
- A `.env` file with database connection variables
- `dotenv` for environment variable loading
- `pg` or another database client
